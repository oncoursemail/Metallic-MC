UNDERSTAND THE FAILURE

Crash diagnostics

Available

Start with the evidence.

Analyze a log excerpt for recognized Minecraft and Java failure signatures. Findings include line numbers and safe next checks; they are hypotheses to verify.

Clicking Analyze sends the excerpt to this signed-in controller. It is not saved or sent to an external analysis service by this endpoint. For offline analysis, run metallic-doctor -log latest.log.

Findings and next checks

The report will contain fixed descriptions and evidence line numbers, without copying private log text.

SERVER OPERATIONS

Every action has an outcome.

Execution not connected

Start, stop, restart, hibernate

Typed lifecycle planning separates requested state from observed process state. A booted process must pass admission before players can enter.

Console, files, and backups

These need a scoped runtime adapter. Console access will address the game process; file access will stay within the server’s writable data.

Suspend and recover

Platform moderation revokes hosted admission. Deletion will quarantine hosted data before retention-based purge. Local private copies remain local.
